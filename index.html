🛠️ Langkah Membuat Pull Request

  1. 1. Fork Repository

    Klik tombol Fork di kanan atas halaman GitHub repository ini.

  2. 2. Clone ke Komputer Kamu 
    git clone https://github.com/<USERNAME-KAMU>/latihan-pr-web.git
cd latihan-pr-web
  3. 3. Buat Branch Baru 
    git checkout -b tambah-profil-<namamu>
  4. 4. Tambahkan Profilmu

    Buka file data/contributors.json, lalu tambahkan objek datamu di dalam array.

  5. 5. Commit & Push Perubahan 
    git add data/contributors.json
git commit -m "feat: tambah profil <namamu>"
git push origin tambah-profil-<namamu>
  6. 6. Buka Pull Request

    Kembali ke GitHub, klik tombol "Compare & pull request", isi keterangan singkat, lalu kirimkan!

Dibuat untuk latihan kolaborasi Git & GitHub Pull Request.

Tinggal edit data/contributors.json dan submit PR kamu!
